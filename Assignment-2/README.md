# Assignment 2 – Responsive Web Design & JavaScript Foundations

## About

This assignment helped me practice responsive web design using HTML and CSS and understand important JavaScript concepts through practical examples.

## Part A – Responsive Web Design

Created a responsive IRP LMS Home Page using HTML and CSS.

### Features

- Navigation bar with logo and menu links.
- Hero section with heading, description and button.
- Learning Journey section with five cards:
  - Learn
  - Practice
  - Build Projects
  - Prepare
  - Get Placed
- Responsive layout for desktop, tablet and mobile screens.
- Sticky navigation bar.

### Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Part B – JavaScript Foundations

Created a JavaScript banking example to practice different JavaScript concepts.

### Concepts Covered

- Data types and type coercion.
- Type conversion using `Number()`.
- Input validation using a function.
- Difference between `var`, `let` and `const`.
- Hoisting and Temporal Dead Zone (TDZ).
- Function declaration and function expression.
- Asynchronous JavaScript using `setTimeout()`.
- Difference between `var` and `let` in loops.

### Technologies Used

- JavaScript
- Node.js

## How to Run

### Part A

Open `part-a-responsive-ui/index.html` in a web browser.

### Part B

Run the following command from the Assignment-2 folder:

```bash
node part-b-javascript/bank.js
```
