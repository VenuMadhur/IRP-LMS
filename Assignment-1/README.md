# IRP LMS Website

## About the Project

This is a simple website created as part of my HTML and CSS assignment.

The website is based on an online learning platform called IRP LMS. It contains three pages: Home, Courses and Contact Us.

## Pages

### 1. Home Page

- Contains the navigation bar.
- Displays a welcome section.
- Shows the learning journey with five steps.

### 2. Courses Page

- Displays nine courses.
- Includes HTML, CSS, JavaScript, React, Python, Java, Spring Boot, Hibernate and Django.
- Uses YouTube videos to show course content.

### 3. Contact Page

- Displays email, phone number and office address.
- Contains a contact form with name, email, subject and message fields.

## How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Use the navigation links to visit the other pages.
